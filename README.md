# C盘深度清理工具 v1.0

> 一款基于 Web 的 Windows C盘 深度清理工具，提供可视化磁盘空间分析、智能文件分类与安全清理功能。

---

## 功能特点

| 功能 | 说明 |
|------|------|
| **智能扫描** | 自动扫描C盘大文件和可清理的临时文件，按安全等级分类 |
| **可视化树状图** | 使用 Plotly Treemap 直观展示磁盘空间占用分布 |
| **一键清理** | 快速清理临时文件、系统缓存、日志文件等安全可删内容 |
| **深度清理** | 同时清理浏览器缓存、应用缓存、下载文件夹大文件等 |
| **系统保护** | 自动排除 Windows 系统文件、Program Files 等关键目录，绝不误删 |
| **安全删除** | 默认移入回收站，误删可恢复；支持永久删除模式 |
| **文件预览** | 清理前展示待删除文件列表，大文件特别标注 |

## 快速开始

### 方式一：直接运行（推荐，无需安装任何环境）

1. 下载 `DiskCleaner_Deploy` 文件夹
2. 双击运行 `启动DiskCleaner.bat`
3. 浏览器将自动打开 `http://localhost:5000`
4. 点击 **「开始扫描C盘」**，等待扫描完成
5. 查看分析结果后，点击 **「一键清理」** 或 **「一键深度清理」**

> 本版本为独立打包版本，**无需安装 Python、Anaconda 或任何依赖库**，开箱即用。

### 方式二：Python 源码运行（开发者）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动应用
python app.py

# 3. 浏览器访问
# http://localhost:5000
```

## 使用说明

### 1. 扫描C盘

点击 **「开始扫描C盘」** 按钮，程序将自动：

- 扫描 `C:\Windows\Temp`、`Prefetch`、`Logs` 等系统临时目录
- 扫描所有用户的 `AppData\Local\Temp`、浏览器缓存、应用缓存
- 扫描 `Downloads` 文件夹中的大文件
- 识别并标记 >100MB 的大文件

扫描结果按三个级别分类：

| 级别 | 图标 | 说明 | 示例 |
|------|------|------|------|
| **安全清理** | 绿色 | 可放心删除，不影响系统和软件 | 临时文件、日志、系统缓存 |
| **谨慎清理** | 黄色 | 删除后可能影响应用使用体验 | 浏览器缓存、下载大文件 |
| **大文件** | 紫色 | >100MB 的非系统文件 | 单独列出供审查 |

### 2. 一键清理（安全模式）

- 点击 **「一键清理」**
- 仅清理 **安全文件**（临时文件、缓存等）
- 弹出确认对话框，显示待删除文件列表
- 大文件（>10MB）会特别标注
- 点击 **「确认清理」** 执行删除
- 文件默认移入 **回收站**，可从回收站恢复

### 3. 一键深度清理

- 点击 **「一键深度清理」**
- 同时清理 安全文件 + 谨慎文件
- 包括：浏览器缓存、应用缓存、下载文件夹大文件等
- 弹出详细的警告提示和文件列表
- 确认后执行删除
- 会清除浏览器缓存，下次打开网页可能需要重新加载

### 4. 树状图交互

- 矩形面积代表文件/文件夹大小
- 点击任意色块可定位到对应文件
- 支持缩放、截图导出等功能
- 右上角工具栏可下载为PNG图片

### 5. 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + S` | 开始扫描 |
| `Esc` | 关闭弹窗 |

## 安全保护机制

### 绝对不删除的目录

```
C:\Windows              (系统目录)
C:\Windows\System32     (系统核心)
C:\Program Files        (应用程序)
C:\Program Files (x86)  (32位应用程序)
C:\Boot                 (引导文件)
```

### 绝对不删除的文件

```
ntoskrnl.exe, bootmgr, pagefile.sys, hiberfil.sys,
swapfile.sys, ntuser.dat, SAM, SECURITY, SYSTEM
```

### 删除安全策略

1. 所有文件在删除前会经过 `is_safe_to_delete()` 安全校验
2. 系统保护路径内的文件即使被误分类也会被拒绝删除
3. 默认使用 `send2trash` 移入回收站（可恢复）
4. 深度清理才支持永久删除（需额外确认）

## 常见问题

### Q: 扫描很慢怎么办？

扫描速度取决于C盘文件数量和磁盘性能。一般1-3分钟内完成。扫描过程中可以点击「取消扫描」中途停止。

### Q: 清理后浏览器书签会丢失吗？

不会。清理的是浏览器缓存文件（临时网页数据），不涉及书签、密码、历史记录。

### Q: 误删了文件怎么恢复？

默认清理模式下，文件被移入回收站。打开桌面回收站，找到对应文件右键「还原」即可。

### Q: 为什么有些文件清理失败？

可能原因：
1. 文件正在被其他程序使用（如浏览器缓存正在使用中）
2. 文件权限不足（可尝试以管理员身份运行）
3. 文件路径过长（Windows 路径长度限制）

### Q: 以管理员身份运行会有更强的清理能力吗？

是的。某些系统临时文件和受保护的缓存需要管理员权限才能删除。右键点击 `启动DiskCleaner.bat` → **以管理员身份运行**。

### Q: 可以在其他盘（D盘、E盘）使用吗？

当前版本专注于C盘清理。如需清理其他盘符，可以修改 `app.py` 中 `scan_paths` 参数。
